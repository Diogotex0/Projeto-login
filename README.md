### 📚 O que aprendi até agora

Durante as aulas, tivemos contato com o Bootstrap, entendendo como frameworks podem acelerar o desenvolvimento front-end, facilitar a organização do código e permitir a criação de interfaces responsivas e mais eficientes.
#### O que é o Bootstrap?
O Bootstrap é um framework front-end (ou seja, um conjunto pronto de ferramentas) utilizado para criar sites e interfaces web de forma rápida, organizada e responsiva.

Ele foi criado para facilitar o desenvolvimento visual, evitando que o programador precise criar tudo do zero apenas com CSS e JavaScript.

[Clique aqui para acessar o bootstrap](https://getbootstrap.com/docs/5.3/examples/)

###### Versionamento de código com Git

🔧 Comandos Git estudados

`git status` — verificação do estado atual do repositório

`git add` — preparação das alterações realizadas no projeto

`git commit -m` — registro versionado das mudanças realizadas

Esses conceitos reforçam a importância da organização e do acompanhamento da evolução do código durante o desenvolvimento.
